# Electronic Tunability of Supported Au-Based Bimetallic Clusters for Catalyst Design

This repository contains the structural data for the research article **"Electronic Tunability of Supported Au-Based Bimetallic Clusters for Catalyst Design"**. 

It provides the optimized geometries for the most stable adsorption modes of bimetallic clusters supported on a defective titanium dioxide surface (TiO<sub>2</sub> with one oxygen vacancy).

## Dataset Description

The dataset consists of Density Functional Theory (DFT) optimized structures of titania-supported Au<sub>7</sub>M<sub>6</sub> bimetallic clusters. The clusters feature 7 gold atoms and 6 atoms of a secondary transition metal (M), where M belongs to groups 9, 10, or 11:
*   **Group 9:** Co, Rh, Ir
*   **Group 10:** Ni, Pd, Pt
*   **Group 11:** Cu, Ag

## Repository Structure

All structural files are provided in the standard Crystallographic Information File (`.cif`) format, which can be easily visualized using standard molecular visualization software (e.g., VESTA, OVITO, etc.).

The repository is organized into a main `geometries` directory, with individual subfolders for each respective bimetallic system:

```text
geometries/
├── AuAg/
│   └── Au7Ag6-TiO2_1vac.cif
├── AuCo/
│   └── Au7Co6-TiO2_1vac.cif
├── AuCu/
│   └── Au7Cu6-TiO2_1vac.cif
├── AuIr/
│   └── Au7Ir6-TiO2_1vac.cif
├── AuNi/
│   └── Au7Ni6-TiO2_1vac.cif
├── AuPd/
│   └── Au7Pd6-TiO2_1vac.cif
├── AuPt/
│   └── Au7Pt6-TiO2_1vac.cif
└── AuRh/
    └── Au7Rh6-TiO2_1vac.cif
```
